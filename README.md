# Canard
Canard70 is my custom 70-key keybard in a 65% form factor! It features hotswappable MX switches, wireless use, month long battery life (estimated) and more!

I created it because I was done with my current clicky keyboard and wanted something with a split spacebar inspired by split ergo keyboards.

## Features:
- Wireless
- Month+ Battery Life
- 65% form factor
- Split Spacebar (4 keys) and extra customizable buttons
- MacBook inspired layout for easy interoperability
- PCB mounted stabilizers
- Minimalist design!
